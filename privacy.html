Политика обработки персональных данных

Настоящая политика определяет порядок обработки персональных данных пользователей сайта stroybf-remont (далее — «Сайт»), принадлежащего исполнителю услуг по ремонту и отделке (далее — «Оператор»).

1. Какие данные собираются

При заполнении формы на Сайте Оператор собирает: имя, номер телефона, комментарий к заявке. Иные данные не запрашиваются.

2. Цель обработки

Данные используются исключительно для связи с пользователем по вопросу расчёта сметы и оказания услуг ремонта и отделки, обсуждаемых на Сайте.

3. Порядок передачи данных

Заявки с формы Сайта передаются Оператору через технический сервис пересылки сообщений в Telegram. Данные не передаются третьим лицам, за исключением случаев, предусмотренных законодательством РФ.

4. Хранение данных

Персональные данные хранятся не дольше срока, необходимого для обработки заявки и оказания услуг, если иное не установлено законом.

5. Согласие на обработку

Заполняя и отправляя форму на Сайте, пользователь даёт согласие на обработку указанных персональных данных в целях, описанных в настоящей политике.

6. Права пользователя

Пользователь вправе запросить удаление своих данных, обратившись к Оператору через контакты, указанные на Сайте.

7. Контакты

По вопросам обработки данных обращайтесь: @stroybf_admin.
